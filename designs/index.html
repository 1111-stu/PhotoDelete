五套 视觉方向

每套都包含 首页(整理)、滑动整理、统计、设置 四个页面,信息结构与数据完全一致,便于横向对比。前三套共用同一套 Moonly 式暗色骨架 —— 近黑画布、整圆胶囊、超大圆角卡片、渐变强调色配深色文字、大而粗的标题 —— 只换气质;后两套是表现力向的对照。

05 · Neo-Brutalism

3px 墨线 + 6px 硬阴影 + 高饱和撞色,Archivo Black 大字。删图像打地鼠一样爽快。

粗野 · 撞色 →
怎么挑 三套暗色是 同一套结构、同一份 DesignSystem,只在三个变量上有差别:画布温度(中性 / 冷 / 暖)、强调色(金 / 月白 / 橘)、照片滤镜(无 / 冷 8% / 暖 6%)。想清楚「界面该是什么温度」就能定下来,选定后其余页面直接沿用 token。
