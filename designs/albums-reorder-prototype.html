长按拖动，空位即落点。

相册现在只有「列表 + 编辑模式」能排序，而且要先切换布局。这一版把三种布局统一成同一套手势：长按抬起、拖动换位、空位站立、松手落位。

01 / 长按与菜单共存

长按 0.45s 抬起。手指移动即进入排序；原地松手仍是原来的整理 / 编辑 / 删除菜单，两个入口互不吃掉。排序的说明收在这个菜单最下面一行小字里——页头不再放提示卡，相册页保持干净。

02 / 空位就是站位

拿起的那一格留在原位变成空槽——与封面同尺寸、同圆角，空槽始终占着新位置。默认画法是虚线（2.5pt、白 34%、虚实间隔 11/9）：虚线本身已经说明「这里可以插入」，颜色不必再喊，琥珀留给真正会执行的行动。实心款是另一种画法，但它只有用琥珀才撑得住识别度——形状和颜色是耦合的，右边可以逐一切换对比。

03 / 让位与落位

越过其他相册中心时，它们 0.22s 平移让位，每次换位一次 selection 触觉；松手后卡片 0.18s 落回空位，轻触觉，随后写入顺序。

04 / 三种布局一致

封面 / 紧凑 / 列表同一套状态机，只有站位尺寸跟随布局。列表改成每个相册一张独立卡片（圆角 16、间距 8），托出的卡片与空位都是完整卡片形状，和网格的站位语言对齐；不再需要「调整顺序」按钮与编辑模式，拖动把手一并去掉。

05 / 边界

搜索非空时禁用排序（沿用现有文案）；拖到滚动区上下边缘 90pt 内自动滚动；无障碍路径为每项「上移 / 下移」动作 + 位置播报。

这是一份交互演示，使用合成相册数据与 CSS 示意封面；不会访问真实相册、不写入任何存储。排序结果只在本次演示中保留，切走布局或刷新即回到初始顺序。
