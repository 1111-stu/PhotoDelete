车窗长卷

直接拿真实车厢照片做窗框：同一扇深蓝灰车窗、同一面车厢墙。向下滚动时，窗本身不动，窗外换成相册里的照片。

隐喻

窗框、黑色胶条、车厢墙、红色车厢标记全部来自真实车厢照片，不是 CSS 画的。相册照片只替换窗外那一块，窗框保持原样。

适合：旅途、风景、车窗外拍到的光；张数不必很多，但每张都值得看大图。

交互

  • 向下滚动 = 车厢前进，一窗接一窗
  • 轻点任意一扇窗 → 看完整照片
  • 顶部细线显示整册浏览进度

为什么这样改

上一版手绘的窗框太干净、太装饰，像七种卡片。真实的年代感来自金属的反光、胶条的老化、墙面的脏和暗——这些用 CSS 画不出来，所以直接用实拍车厢。

细节

  • 同一张窗框重复，变化只发生在窗外
  • 照片按窗口比例裁切，保留玻璃反光
  • 第一扇窗贴一张奶油色线路卡
  • 原图只清掉了播放器的「实况」和分享按钮
