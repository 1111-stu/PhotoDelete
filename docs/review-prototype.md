# 整理操作页原型

整理照片时只有两个手势。上滑把当前照片收进待删除，下滑把它放进相册。左右滑动只用来翻页。

底栏四个按钮：撤销、收藏、分享、完成整理。

## 两种进入方式

从随机整理进来，照片下面直接是底栏。

从某个相册进来，底栏上方多一行方形缩略图，可以横滑。随机整理没有这一行。

## 手势

| 手势 | 结果 |
| --- | --- |
| 上滑 | 卡片缩小，飞进右上角垃圾桶。超过阈值就收进待删除，并切到下一张。未超过阈值弹回原位。 |
| 下滑 | 打开「放进哪个相册?」。 |
| 左滑 / 右滑 | 切换上一张或下一张，不删除、不保留、不收藏。 |

## 随机整理

```text
┌──────────────────────────────────┐
│ ‹          2 / 10 ⌄           ⌂ 🗑 │
│         本轮待整理 8 张            │
│                                  │
│        ┌────────────────┐        │
│        │                │        │
│        │     当前照片     │        │
│        │   [ 加入相册 ]   │        │
│        └────────────────┘        │
│     2026年1月12日 · 18:27 · 449KB │
│                                  │
│ 撤销      收藏      分享    完成整理 │
└──────────────────────────────────┘
        ← 上一张          下一张 →
```

顶栏中间是本轮进度。右上角垃圾桶是上滑的落点。照片上的「加入相册」和下滑进入同一个抽屉。

## 从相册进入

```text
┌──────────────────────────────────┐
│ ‹          2 / 10 ⌄           ⌂ 🗑 │
│         本轮待整理 8 张            │
│                                  │
│        ┌────────────────┐        │
│        │     当前照片     │        │
│        │   [ 加入相册 ]   │        │
│        └────────────────┘        │
│     2026年1月12日 · 18:27 · 449KB │
│                                  │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐  │
│  │  │ │▓▓│ │  │ │  │ │  │ │  │ → │
│  └──┘ └──┘ └──┘ └──┘ └──┘ └──┘  │
│         方形缩略图，可横滑          │
│                                  │
│ 撤销      收藏      分享    完成整理 │
└──────────────────────────────────┘
```

缩略图是这一册相册里的照片，横滑浏览。当前张高亮。

## 上滑

```text
┌──────────────────────────────────┐
│ ‹          3 / 10 ⌄           ⌂ 🗑 │
│         本轮待整理 7 张         ↗□ │
│                                缩小 │
│                                  │
│              ┌────────┐          │
│              │ 飞出中  │          │
│              └────────┘          │
│                                  │
│ 撤销      收藏      分享    完成整理 │
└──────────────────────────────────┘
```

## 下滑

```text
┌──────────────────────────────────┐
│  ✕      放进哪个相册?      ▦   ⚙  │
│  快捷相册                        │
│  ┌────────────────────────────┐  │
│  │     暂未添加快捷相册         │  │
│  └────────────────────────────┘  │
│  🔍 搜索相册                   📁 │
│  [全部]                         + │
│  ┌──── 微信              ↑ ┐     │
│  ┌──── 小红书            ↑ ┐     │
│  ┌──── 醒图              ↑ ┐     │
│  ┌──── Weixin            ↑ ┐     │
│  还未选择            [ 完成并继续 ] │
└──────────────────────────────────┘
```

点某一行的箭头把当前照片放进该相册。点「完成并继续」回到下一张。

## 左右翻页

```text
        ┌────┐ ┌────────┐ ┌────┐
        │上一张│ │ 当前照片 │ │下一张│
        └────┘ └────────┘ └────┘
              ← 拖动翻页 →
```
