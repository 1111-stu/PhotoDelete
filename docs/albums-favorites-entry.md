# 相册页「个人收藏」入口：交互决策与 ASCII 原型

决策日期：2026-10-11。  
状态：**产品定稿，已落地代码（2026-10-11）；待真机回归。**  
范围：相册 Tab 置顶展示系统「个人收藏」、进入现有浏览器/整理的闭环；不含首页专项清理改版、不含 App 内第二套收藏暂存区。

相关背景：

- 整理时点心形 = 立刻写系统 `PHAsset.isFavorite`（与系统「照片 → 个人收藏」同一标记），不是 App 暂存。
- 收集箱 / 本轮结算见 `organize-collection-bin-flow.md`。
- 相册排序与三种显示方式见 `style.md` §6.4、`albums-reorder-research.md`。

---

## 1. 一句话定稿

**个人收藏是系统智能相册；主入口钉在相册页顶部「系统」区；点进复用现有相册浏览器与整理；不进首页「专项清理」，不做 App 内收藏箱。**

---

## 2. 核心原则

| # | 原则 | 说明 |
| --- | --- | --- |
| P1 | 系统真相 | 读写都是系统 `isFavorite` / `smartAlbumFavorites`；App 不维护第二份收藏集合 |
| P2 | 相册主入口 | 展示与回看放在相册 Tab；与「我的相册」并列但分区 |
| P3 | 保留 ≠ 清理 | 不进首页「专项清理」（那是可删/可压对象）；收藏是保留信号 |
| P4 | 置顶不可排 | 「个人收藏」固定在系统区；不参与用户相册长按拖拽排序 |
| P5 | 复用路径 | 点进 → 现有 `AlbumBrowser` → 现有整理；不新做专用收藏页 |
| P6 | 空则隐藏 | 系统收藏数量为 0 时整卡不出现（与现有 `systemAlbums` 只收非空智能相册一致） |

---

## 3. 现状与缺口

| 层 | 现状 | 缺口 |
| --- | --- | --- |
| 写入 | 整理点心形 → `setPhotoFavoriteImmediately` → 系统收藏 | — |
| 数据 | `DataManager.systemAlbums` 已扫 `smartAlbumFavorites`；`photoLibraryManager.favorites` 有缓存 | — |
| 相册 UI | `AlbumsView` 只渲染 `getUserAlbums()` | **系统收藏进了数据、没上 UI** |
| 首页 | 专项清理：相似 / 视频 / 截图 / 实况 / 录屏 | 无收藏入口（保持如此） |
| 旁路 | 相册浏览器内可筛「仅收藏」；最近整理可记 favorited | 无「看全部个人收藏」闭环 |

用户在整理里收藏后，App 内难以回看——本需求补的就是这条回路。

---

## 4. 交互决策表

| 入口 / 动作 | 行为 | 不做什么 |
| --- | --- | --- |
| 相册页「个人收藏」卡 | 打开该相册的浏览器（与用户相册同一套） | 不直接全屏进整理（除非浏览器已有「开始整理」再进） |
| 浏览器内整理 | 队列 = 当前收藏集成员 | — |
| 整理中点心形（已收藏） | **取消收藏**（toggle）；可撤销 | 不是「再加入一次」 |
| 整理中上滑待删 | 进全局 `deleteCandidates` | **不**清系统收藏标记 |
| 从其他相册上滑待删 | 同上：只进收集箱 | **不**移出用户相册 / 智能相册 |
| 长按「个人收藏」 | 无菜单、不可拖 | 不做编辑 / 删除 / 排序 |
| 长按「我的相册」 | 照旧：整理 / 编辑 / 删除 + 拖排序 | — |
| 搜索 | 标题命中则显示收藏卡；仅搜用户相册时系统区可整段隐藏 | 搜索时仍禁用用户相册排序 |
| 数量 = 0 | 隐藏个人收藏卡（及空「系统」区） | 不占空位、不引导「去收藏」 |
| 首页专项清理 | — | **不加**「收藏」行 |

### 4.1 与待删除 / 收藏的交叉（已实现，文档固化）

| 场景 | 结果 |
| --- | --- |
| 已收藏 → 进收集箱 | 系统收藏**保留**；仅 App 暂存待删 |
| 待删除中 → 再点收藏 | 先移出收集箱，再标系统收藏（现有互斥） |
| 本轮结算「本次收藏」 | 只计净**新增**收藏（`favoriteActionCount`）；取消收藏不减成负数，下限 0 |
| 收集箱确认真删 | PhotoKit 删除后整库移除，收藏随之消失 |

## 5. ASCII 原型

### 5.1 相册页 · 封面布局（有收藏）

```
┌──────────────────────────────────────┐
│  相册                          [▦]   │  ← 右上：显示方式（不变）
│  N 个相册                             │
│  [🔍 搜索相册……………]          [＋]   │
│                                      │
│  系统                                 │  ← 小节标题（次级字）
│  ┌────────────┐                      │
│  │ ▓▓▓▓▓▓▓▓▓▓ │                      │
│  │ ▓ 封面图 ▓ │  个人收藏            │  ← 置顶；可用心形 tint
│  │ ▓▓▓▓▓▓▓▓▓▓ │  128                 │
│  └────────────┘                      │
│                                      │
│  我的相册                             │  ← 可排序区从这里开始
│  ┌────────────┐  ┌────────────┐      │
│  │  封面 A    │  │  封面 B    │      │
│  │ 旅行 42    │  │ 家人 18    │      │
│  └────────────┘  └────────────┘      │
│  ┌────────────┐  ┌────────────┐      │
│  │  …         │  │  …         │      │
│  └────────────┘  └────────────┘      │
└──────────────────────────────────────┘
```

紧凑布局：系统区同样置顶一格（或一行），规格跟用户相册格子一致，但**不参与 reorder 槽位**。

### 5.2 相册页 · 列表布局

```
┌──────────────────────────────────────┐
│  相册                          [▦]   │
│  [🔍 搜索…]                   [＋]   │
│                                      │
│  系统                                 │
│  ┌────────────────────────────────┐  │
│  │ ♥  个人收藏              128 › │  │  ← 单行卡；不可拖、无长按菜单
│  └────────────────────────────────┘  │
│                                      │
│  我的相册                             │
│  ┌────────────────────────────────┐  │
│  │ ▢  旅行                   42 › │  │  ← 长按仍可排序 / 菜单
│  └────────────────────────────────┘  │
│  ┌────────────────────────────────┐  │
│  │ ▢  家人                   18 › │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

### 5.3 端到端路径

```
相册 Tab
  └─ [个人收藏]（系统区，count > 0）
        → AlbumBrowser（现有网格 / 筛选 / 整理入口）
             → SwipePhotoView（队列 = 收藏集）
                  ├─ 心形 ──→ toggle 系统收藏（在此场景多为取消）
                  ├─ ↑ ──→ 全局收集箱（不清 isFavorite）
                  └─ ✓ ──→ 本轮结算（本次收藏 = 净新增，常为 0）
```

### 5.4 能力对照（个人收藏 vs 我的相册）

| 能力 | 个人收藏 | 我的相册 |
| --- | --- | --- |
| 点按进浏览器 | ✓ | ✓ |
| 浏览器 → 整理 | ✓ | ✓ |
| 长按菜单 | ✗ | 整理 / 编辑 / 删除 |
| 拖拽排序 | ✗ | ✓（搜索空时） |
| 新建 / 改名 / 删相册 | ✗ | ✓（权限允许时） |
| 区标题 | 系统 | 我的相册 |

## 6. 文案

| 位置 | 文案 | 备注 |
| --- | --- | --- |
| 区标题 | 「系统」 | 便于日后扩展其他钉住的智能相册；若只永远一个钉，可改为「收藏」——实现前锁定为「系统」 |
| 行/卡标题 | 沿用 `L10n.favoritesCategoryTitle`（Favorites / 个人收藏等） | 跟系统本地化气质；不硬编码「收藏」 |
| 数量 | 无千分位整数 | 对齐 `style.md` |
| 副文案 | 列表页不强制写「来自系统照片」 | 避免噪音；进一次即懂 |

浏览器内已有「仅收藏」内容筛，**保留**（场景：在某个用户相册里看哪些打了心），与本入口不冲突。

## 7. 数据映射（实现对照）

| UI | Source of truth | 注意 |
| --- | --- | --- |
| 是否显示个人收藏卡 | `DataManager.favoritesAlbumForDisplay()`（`systemAlbums` 中 `type == .favorites` 且 `photosCount > 0`） | 勿只靠 UserDefaults |
| 封面 | 现有 `AlbumInfo.thumbnailAsset` / 智能相册首张 | 与用户相册同一套缩略图加载 |
| 点进 | `AlbumNavigationDestination.browser(favoritesAlbumInfo)` | 与用户相册同 destination |
| 整理队列 | 相册成员或 `photoLibraryManager.favorites` | 取消收藏后会话刷新（现有 `onChange(favorites.count)` 已有） |
| 用户相册列表 | 仍只 `getUserAlbums()` + 自定义排序 | **不要**把 favorites 塞进 `customAlbumOrder` |
| 旧 `favoriteCandidates` | 仅遗留迁移；整理写收藏已走 immediate | 本需求不复活暂存箱 UI |

## 10. 决策日志（对话收敛）

1. 收藏写的是系统个人收藏，不是 App 暂存 → 展示应对齐系统相册心智。  
2. 主入口选相册页置顶，不选首页专项清理（保留 vs 清理语义分离）。  
3. 不做 App 内收藏箱；进收集箱不清 `isFavorite`；进收集箱也不移出用户相册。  
4. 整理内心形始终为 toggle；在收藏集内整理再点 = 取消收藏；结算「本次收藏」只计净新增，不为负。  
5. 本轮系统区只钉「个人收藏」一个；ASCII 定封面 + 列表两版，紧凑跟同一信息架构。  
6. 先落本文档，再改 `AlbumsView`。
