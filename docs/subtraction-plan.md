# 删图二开：减法计划

用户打开这个 App，是因为相册太满，想安全地删掉不想留的。二开只服务这件事。

主循环固定为四步：选队列、逐张滑动、确认后才删除、手滑可以撤销。不能缩短这四步的功能不做。

界面重做和付费墙重做都放在砍功能之后。先删掉不会留下的页面，再重做首页队列和滑动卡片。

## 做完后的产品

底栏只有两个：整理、设置。

整理页的队列：

1. 继续未整理的照片
2. 截图
3. 视频
4. 相似照片（付费）
5. 大文件（付费）

其次才是某一个相册，或按月整理。相册和进阶不再是底栏。

整理中的屏幕：

- 全屏一张照片。左滑删除，右滑保留，可以撤销，底部显示待确认数量。
- 完成后进入同一张确认页，缩略图复核，再交给系统删除。
- 结果页只写：删了多少张、大约多少空间、可在「最近删除」找回。

设置只放：照片权限、清空本机进度、跟随系统 / 浅色 / 深色、反馈、隐私。

## 保留

这些是刚需，二开继续做。

| 功能 | 原因 |
| --- | --- |
| 照片权限 | 完整、有限、拒绝三种状态都要有。有限照片库是真实使用路径。 |
| 左滑删除、右滑保留 | 主循环。手势固定这一套。 |
| 待删除 + 批量确认 | 确认前不写相册。这是和「滑一下就删」分开的地方。 |
| 撤销上一步 | 只撤销最近一次本地判断。 |
| 全部 / 截图 / 视频 | 三种清理意图最清楚。截图和视频是用户自己知道该删的队列。 |
| 本机处理、无账号 | 引导和设置里各说一次。照片不上传。 |
| 清理结果 | 确认成功后只报本次张数和大约空间。 |
| 相似照片 | 值得付费的能力。从进阶页挪到首页队列，点进去再付费。 |
| 大文件 | 和相似照片一起构成付费理由。按占用从大到小列，仍走同一套确认删除。 |

## 收束

留下一半，去掉多余入口和状态。

| 现在 | 收成 |
| --- | --- |
| 相册是独立底栏，含创建、重命名、删空相册、自定义排序 | 相册只作为整理来源，放在首页第二级。创建和改名交给系统相册。 |
| 按日、周、月、年整理，另有「完整时间列表」 | 只留「按月」。 |
| 上滑收藏是默认手势 | 从默认手势拿掉。系统相册已经能收藏。 |
| 四套付费主题，加上浅色深色 | 只留跟随系统、浅色、深色。 |
| 设置里有语言、触感、统计、成就、创作者、其他 App | 语言跟随系统，触感默认开启。设置只留权限、清空进度、外观、反馈、隐私。 |

## 砍掉

| 功能 | 原因 |
| --- | --- |
| 图片压缩 | 这是压缩工具，不是删图。质量问题和客服成本单独成一条产品线。 |
| 视频压缩 | 还要处理 iCloud 下载和转码，和「确认后删除」不是同一条任务。 |
| 成就、连续天数、徽章 | 清理结果页已经够。不再做徽章页和连续天数。 |
| 随机整理、历史上的今天 | 用户来是为了删已知垃圾。 |
| 地点整理 | 要做地名解析，清理意图弱。 |
| 未归类、实况、收藏分类 | 实况是格式，收藏不是垃圾，未归类要先算相册成员。都不是清理队列。 |
| 双排浏览 | 和卡片模式双份交互。只留一种全屏卡片。 |
| 手势预设与自定义 | 三套预设、自定义映射和迁移提示。改了更容易误删。 |
| 整理时归入相册 | 下滑归类、移出相册、快捷相册，把第二个任务塞进删除手势。 |
| 进阶时间仪表盘 | 日周月年摘要。未购买时的假数据相册不再展示。 |
| 付费主题 | 清透蓝、鼠尾草、暖砂、石墨。不出现在付费对比里。 |
| 跨 App 推广与创作者页 | 不服务这次整理。 |

引导页里介绍压缩和进阶清理的那一页一并删掉。整理过程中的模式提示、相册快捷提示、删除按钮提示、手势更新提示、下滑提示也不再保留。

## 实施顺序

1. **定死主循环。** 选队列、滑动、确认、撤销。新功能如果不能缩短这四步，就不做。
2. **收底栏。** 整理、设置。相册和进阶离开底栏。
3. **砍功能。** 压缩、成就、主题、随机、地点、历史上的今天、手势自定义、双排浏览、相册管理、整理时归入相册、进阶时间仪表盘、推广页。`AdvancedView` 和 `TwoRowPhotoBrowserView` 不再承担产品。
4. **收付费。** 付费只挂在相似照片和大文件。一个价格，一个入口，不展示假相册。
5. **重做界面。** 首页队列和全屏滑动：一张照片、两个方向、一个确认。

第 5 步之前不给将要删掉的页面做新界面。
